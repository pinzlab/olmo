# Olmo

Olmo is a small, strongly typed data-modeling and validation library for TypeScript.

It is designed to make working with external data, HTML forms, and FormData simple and type-safe.`

## Available Scripts

- `npm run dev`: Run `tsup` in watch mode.
- `npm run build`: Build the library (outputs to `dist/`).
- `npm run test`: Run the test suite using Vitest.
- `npm run test:watch`: Run the test suite in watch mode.
- `npm run lint`: Lint the codebase using ESLint.
- `npm run format`: Format the codebase using Prettier.
- `npm run typecheck`: Check TypeScript types without emitting files.
